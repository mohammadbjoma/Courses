# 📚 Courses

An **education-focused Django web application** for browsing, managing, and interacting with online courses — designed to showcase backend logic, user roles, and course content management.

---

## 🚀 Project Overview

This application allows users to:

* View a list of courses
* Enroll or interact with courses
* Explore course details
* Manage courses (if admin)

Built with clean Django structure, modern UI, and easily extensible components.

---

## 🌟 Features

✔️ User authentication
✔️ Course listing and detail pages
✔️ Admin course management
✔️ Pagination & search features
✔️ Responsive UI using Bootstrap
✔️ Clean Django MVC architecture
✔️ Scalable and maintainable

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/mohammadbjoma/Courses.git
cd Courses
```

### 2️⃣ Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Apply database migrations

```bash
python manage.py migrate
```

### 5️⃣ Run the development server

```bash
python manage.py runserver
```

🧭 Open in your browser:

```
http://127.0.0.1:8000/
```
